# Dimas Baskara · Portfolio

Personal engineering portfolio focused on reproducible data pipelines, database architecture, and applied analytics.

Built with [Astro 5](https://astro.build), TypeScript, Content Collections, and vanilla CSS design tokens. No external UI frameworks.

## Highlights

- Editorial design system with dark and light theme support.
- Astro View Transitions with zero layout shift or theme flash.
- Verified WCAG AA accessibility compliance (100% Lighthouse score).
- Static generation with deterministic assets and minimal footprint.

## Commands

```sh
npm install      # Install dependencies
npm run dev      # Start dev server at localhost:4321
npm run check    # Run Astro and TypeScript diagnostics
npm run build    # Build static production site to ./dist/
npm run preview  # Preview production build locally
```
